📄 SmartDocs AI – Multi PDF RAG Chatbot

An AI-powered chatbot that allows users to upload multiple PDF documents and ask questions using natural language.

🚀 Features
Upload multiple PDFs
Ask questions from documents
AI-generated answers using RAG
Source document references
ChatGPT-style interface
🧠 Tech Stack
Python
Streamlit
LangChain
FAISS
HuggingFace Transformers
▶️ Run Locally
pip install -r requirements.txt
streamlit run app.py
💡 Use Cases
Research documents
Legal files
Business reports
Study material
